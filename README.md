# PETFLOW V6 Online

Base online do PETFLOW para publicar na Vercel e evoluir com Supabase.

## Rodar local
```bash
npm install
npm run dev
```

## Publicar online
1. Criar conta na Vercel.
2. Enviar este projeto para GitHub.
3. Importar o repositório na Vercel.
4. Configurar Supabase depois que o banco estiver criado.
